# Hydropower Production & Revenue Analysis

## Project Overview

This project analyzes hydropower production, electricity prices, water utilization, and estimated revenue over a three-month period (January–March 2025).

The goal is to identify key production drivers, evaluate operational performance, build a regression model, and explore potential production improvement scenarios.

## Tools & Technologies

- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- Google Colab / Jupyter Notebook
- Power BI
- Excel / Google Sheets
- Statistical analysis and regression modeling

## Project Structure

- `data/` — source and processed datasets
- `notebooks/` — Python analysis and modeling
- `powerbi/` — Power BI dashboard
- `reports/` — final analytical reports
- `results/` — statistical, regression, and scenario analysis outputs

## Key Results

- Total energy production: **73,835.20 MWh**
- Estimated total revenue: **€4,166,939.38**
- Average daily production: **820.39 MWh**
- Average electricity price: **€56.53/MWh**
- Water utilization ratio: **87.35%**
- Regression model R²: **0.9910**
- Regression model MAE: **9.70 MWh**

## Key Findings

- Energy production was strongly correlated with turbine flow and water inflow.
- Production declined by approximately 28.3% from January to March.
- Electricity price had a strong relationship with estimated revenue.
- Scenario analysis explored the potential impact of changes in turbine flow, net head, and efficiency.

## Interactive Dashboard

The Power BI dashboard provides interactive exploration of production, revenue, electricity prices, and operational indicators, including daily-level analysis.

## Reports

The project includes final analytical reports in English and Russian.

## Limitations

The analysis covers 90 daily observations from January to March 2025. Revenue is estimated from production and electricity prices and may differ from actual realized revenue. Correlation does not imply causation. Further validation using longer historical datasets is recommended.
